# v0.4.14 · 试用确认提速

- 打开试用只读取当前任务和成果，不再加载全部执行历史、会话和审查正文。
- 用户确认结果不再同步遍历源码或近万份安装文件。项目后续修改 AGENTS.md 等文件，不再要求为旧任务重新开单才能确认。
- 用户确认记录明确保存原技术核验及时间，不将确认操作描述为重新检查源码或安装程序。交付、安装和独立审查仍分别保留实际记录。
- 保存成功立即关闭弹窗并提示，任务列表在后台同步；失败继续在原表单显示，不误报成功。
- 审查汇总按当前执行查询关联记录，避免对每项任务反复读取全表历史。

保留最新页面版本、当前成果引用和用户逐项确认校验。更新沿用便携安装流程，保留数据与回滚材料。
