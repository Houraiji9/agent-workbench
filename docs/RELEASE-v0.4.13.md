# v0.4.13：按需方案交接

工作台继续向桥梁和记录者靠近：规划、执行、审查与收尾围绕本轮方案流转，不默认把整个项目重新读一遍。

- 调度与项目的默认上下文只提供当前摘要、计数和查询入口；历史检索默认返回定位摘要，支持分页和指定详情，完整记录保留。
- 方案可保存正文或文件位置。文件可标明适用角色、行范围和补读原因；审查重点与成果目录随单传递。
- 任务详情新增“方案与交接”，可以查看方案、成果地址和各角色按需资料，不新增必填表单。
- 执行与审查可单独展开方案、文件、要求或历史。同会话增量只发送变化文件与新问题，自动审查提示明确只从本轮变化及直接影响开始。
- 简短计划可省略无关的非目标、理由、资源说明等字段。必要补读不受建议清单限制，失效建议不再牵连其他合法资料读取。
- 口述补充可在当前任务修订方案与资料，保留旧内容。模型、预算和流程是建议；真实来源、目录保护及用户验收仍分别记录。

这些措施减少默认传输的文字，不声称可以控制各客户端的自主阅读或保证固定 token 节省比例。具体用量以客户端实际记录为准。
