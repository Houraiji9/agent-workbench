## v0.2.0 更新验证

本节对应 0.2.0 整体优化。运行环境为 Windows x64、Node.js 24.18.0、Chrome 和 Electron；PowerShell 检查分别使用系统 Windows PowerShell 5.1 和 Codex 附带的便携 PowerShell 7.6.5，不把便携运行时表述为系统安装。

- TypeScript 类型检查、Vite 页面构建和桌面构建通过。生产依赖版本未变；本轮没有重新进行漏洞审计。
- 非桌面全量单元回归原始结果为 255 项：252 通过、2 失败、1 跳过。这次运行没有全绿。失败来自负载下 SSE 固定计时假设及失败路径未释放资源造成的清理错误；修正后 integrations 与 workflow-api 整文件复跑 11/11 通过。原始失败记录保留。
- 新协议与部署专项原始结果为 16/17；唯一失败是跨 Run 请求在认证层返回 401，而测试只接受 403。改为验证两种拒绝状态后，该接口测试复跑通过。部署门禁、上下文隔离、会话绑定、冻结返修意见、收尾结果覆盖和幂等检查均有通过记录。
- 选定的 33 项浏览器场景首轮 28 通过、5 失败，失败项使用了待安排列表默认展开的旧交互预期。修正操作预期后分组复跑 7/8，余下一项重载后展开操作由执行顺序专项 2/2 验证通过。新增界面专项最终 4/4，覆盖 100 项合成待办、搜索/排序/加载更多、项目说明首屏、真实分支汇合与短续作。没有将这些结果说成重新执行了全部历史浏览器用例。
- 桌面生命周期专项 1/1 通过，覆盖最小化、托盘关闭、恢复同一窗口和退出释放后台。
- 全量单元中按环境跳过的完整便携更新检查，随后提供实际候选目录和 ZIP 单独执行，1/1 通过。测试从模拟旧版本完成检查、下载校验、正常退出、换包和重启；需求、连接配置、本地密钥、执行包与项目 MCP 保留，旧程序文件移除并保留数据库快照。
