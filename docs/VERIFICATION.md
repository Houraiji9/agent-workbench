Token Monitor 0.65.0 的三个接口兼容性来自用户在另一台 Windows 10 19045 x64 上的实测反馈，已成功读取真实额度；本轮未在那台电脑重新安装。0.77.0 桌面端尚未验证。此次不读取开发者本机账号或凭据，不将模拟上传标成真实账号接入。

GitHub 发布先经过私有仓库阶段，再针对候选源码和包体进行独立隐私与安全审查。各发布的具体 commit、包体 SHA256 和最终审查结论记录在 GitHub Release 中。

限制：只针对 Windows x64 桌面流程验证；未测其他操作系统、所有模型客户端或其他数据源版本。EXE 没有数字签名与自动更新。数据保存在本机明文目录，备份需要自行保管。上游模型、套餐和接口可能变化，可编辑资料并按新版本重新核验。
