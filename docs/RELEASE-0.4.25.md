# 0.4.25：项目工作群

新增项目工作群：选择负责人和成员，在群里交代目标、派活、讨论并查看真实回报。Codex 和 Claude 可以担任负责人，成员调用使用本机客户端及独立原生会话。普通协作沿用已保存的群授权，忙时排队，结果自动回流，无需用户反复转述。

本版保留原有任务、执行、外部服务和独立审查记录。群消息、实际启动、成员结果与用户验收分别展示；支持增量消息、历史分页、停止与有界自动接话。群成员可按原连接授权使用外部 API/CLI/MCP 服务。

Harness 群成员可显式选择桌面中已经配置的模型，并在本次 headless 调用临时复用对应路由和凭据引用；不更改全局默认配置。原生登录、密钥和额度错误会显示在任务中，结束后的调用可以继续。

使用入口和权限说明见 [项目工作群](WORKGROUPS.md)。本地安装、真实客户端验证和独立审查的结果分别保存于交付证据，发布说明不代替用户验收。0.4.25 当时为本机交付，其功能纳入 0.4.26 发布包。
