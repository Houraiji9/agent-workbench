# 查看成果所在文件夹

项目的“成果”页、任务详情的“成果”列表，以及图片等文件的预览窗口，都能看到文件夹位置。

- **打开文件夹**：打开 Windows 资源管理器，并选中对应文件。
- **复制路径**：复制完整文件夹路径，可以粘贴到资源管理器地址栏。
- **打开归档文件夹**：在预览窗口中找到工作台保存的交付副本；原文件被移动或删除时，列表也会出现这个入口。

成果卡片较窄时，长路径会省略显示。鼠标停留在路径上可以查看完整内容，也可以打开预览查看或直接复制。

工作台中的预览和下载使用交付时保存的归档副本；“打开文件夹”对应原文件的位置，方便继续整理和编辑。以前提交的成果同样可以使用这些入口。
