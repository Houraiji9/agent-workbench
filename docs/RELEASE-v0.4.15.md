# v0.4.15 · 缺会话编号自动新开

- 已结束的调用没有可用续接编号时，普通重试自动新开会话，不再要求用户额外确认 `fresh_session`。
- 有可用的最近会话仍优先续接；最近一次调用无法续接时，不跳回更早、缺少后续工作的旧会话。
- 新会话获取本轮简版资料，不沿用旧会话的“已读”状态；只记录新开原因和前一调用，不伪称上下文已复用。
- 已接单但失败的审查可自动新开重试，旧审查单、调用失败与真实报告保留。
- 自动派审失败与手动审查分别记录。执行者可以按用户安排交付后停止，由用户把本轮成果交给选定的独立审查者，无需恢复旧自动会话。

本次只调整会话选择；原客户端仍活动时不重复启动，客户端自身授权和用户对主执行者的启动选择继续有效。
