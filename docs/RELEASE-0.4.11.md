# 0.4.11

工作台以引导、记录和汇总为主。前序任务、成员能力标签、额度快照、阅读清单与子代理预算改为建议；当前会话可以继续办理，无需为了阶段顺序重新转单。用户仍掌握外部主执行的启动与最终验收。

- 同一执行再次交付时保留旧产物与报告。晚到的旧版回报归档，当前进度与审查依据不被覆盖。
- 执行单、审查单和规划上下文默认给简版；同会话复审提供变化，完整要求和项目经验按需读取。
- 审查支持短 JSON，由连接补齐任务编号。模型名称是记录信息，不作为接单或回传门槛。
- 支持 Grok Build 1.0.41 的原生流式事件、会话与累计用量；未完成的会话可续接，取消不记为通过，工具输出与思考不当作审查报告。
- 任务安排变化只留下提醒，不自动中止正在工作的 Agent。用户明确停止仍生效。
- 便携安装与通用部署可以先登记真实结果，审查状态独立记录；收尾可保存未验证项，不替用户验收。

凭据、项目目录、真实来源与客户端自身授权仍由相应机制保护。程序不会将未知状态、进程退出或作者陈述当作独立审查通过。
