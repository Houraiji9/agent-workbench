# 项目管理简明指南

## 从想法到规划

“提需求”只列出活动项目；当前项目排在前面，其余按最近访问或需求编辑记录排序。选择项目，写下一处需求描述，并在同一处查看或调整项目、重要程度、规划方式、交付安排和审查安排，再点“现在开始”。想法还没确定时可以“先记下来”。

个人工具通常选“普通”，优先使用够用的经济模型；公司对外交付等重要工作选“重点”，主执行、子代理和审查均要求当前可用的最高能力档，并安排完整独立审查。资源不足时重新规划，不自动降档。

交付安排可沿用项目设置、由大脑按本次需求安排，或由你指定。沿用项目设置时会记录继承来源；你明确指定时会记录本次设置。选择“由大脑安排”才表示允许规划者结合需求原话确定完整交付内容；旧任务的 `source` / `none` 默认值不构成你的限制。例如机器人项目可交付源码并部署到线上，无需填写本机程序目录。安装、运行检查和回退细节可留给规划者补齐；不要填写密码。

需求、重要程度、规划方式、交付安排和审查安排都在提需求处直接可见；按需补充产出要求和验收标准。默认由 Codex 规划；希望在普通 GPT 聊天里规划小需求时，选择相应规划方式，计划最多三项任务。“普通 / 重点”表示质量与模型要求，和使用哪种聊天规划方式无关。默认安排完整独立审查；有限审查或不审查须由你明确选择。你在描述中口述的安排仍优先，规划者不能代替你验收。

只有明确配置了工作台 MCP 的聊天才能直接读取资料和提交计划；普通 GPT 聊天不会自动接入。

普通 GPT 聊天和标准复制入口会附带当前项目的有界摘要，其中事实标注来源和生成时间；其中的 stage 可能滞后，不能当成新的用户指令。没有 MCP 时，复制需求资料并粘贴到你选择的 GPT 聊天，再把完整计划回复粘贴回工作台。先查看分工预览，确认后保存。连接版聊天规划仅开放读取本需求规划资料和提交计划两个工具，不会在聊天中执行任务。

首页“待试用”项目提供直接确认框，操作按钮会常驻显示。执行单可直接复制；复制失败时可查看并复制文本。复制只准备内容，不会派发执行。

任务过程会记录计划来自聊天粘贴、聊天规划连接还是其他规划连接。规划者提供的名称和模型单列为“自述，未核验”；没有提供的模型保留未知，不自动标成 Codex。

## 收纳暂缓

“收纳并暂缓新安排”会把项目从日常项目和需求列表中隐藏，暂停之后的新安排。已经运行的客户端调用会继续，不会被收纳操作停止。需要继续安排工作时，在“收纳暂缓”列表恢复项目。

## 查看和整理项目文件

项目文件可以按成果、工程、过程、测试、无效、待清理、备份和待分类查看。每个文件的分类、有效性（当前/历史/无效/未知）和保留状态（保留/待清理/已移走）分别记录；用途说明也独立保存。来源未知表示系统没有确认来源，不能据此认定文件无用。

文件分类只记录信息，不会移动文件。要移入待清理，先把文件的保留状态设为“待清理”并说明原因；随后逐项选择，勾选“这些是我创建且不再使用的临时文件，没有其他引用”，再写明本次移动原因并提交。系统保留移动记录和恢复入口，不提供删除操作。不能确认用途、来源或是否仍被引用时，先保留原文件。

成果预览受支持的文本会以文本显示。HTML 以禁用脚本的隔离页面静态预览；它不是可运行或可验证的程序。

## 用量和项目流程

项目流程只归入能通过明确项目、任务和执行记录关联的数据。归属不明确的客户端、外部或历史数据不会猜测归到项目。

用量只展示来源已提供且可确认的数值小计；缺失指标会标为缺失，不按零计算。可按执行、审查和收尾阶段筛选用量；关系图仍保留项目全貌，可折叠历史和子代理。Token 预算是提醒值，工作台不会据此保证硬性封顶。

## 模型、子代理与交付

每项任务开始前可检查本次主模型、允许的子代理及子模型。客户端内部的原生子代理只能收到允许名单和范围要求；工作台目前不能强制拦截，也不能保证完整观测。登记给工作台管理的委派会按其授权与回报规则记录。

项目默认设置先选择适用的 Agent，再从该成员的模型中选择；每个 Agent 分别保存，其他成员不会套用这份模型设置。“通用默认”保存预算和上下文等安排，不固定主模型或子模型。任务或需求中的明确设置仍优先，已发出的执行单保持原设置。

普通需求默认安排完整独立审查；如需有限审查或不安排审查，在“规划与审查”里修改并写明范围或原因。重点需求固定为完整独立审查。

项目交付设置说明成果是什么、在哪里使用。选择本机或线上后，执行者仍须交付部署及运行检查证据；工作台便携程序会核对安装清单，其他环境的证据注明由执行者报告，不冒称工作台已经连接远程服务器核验。

## 项目用量的读取方式

“用量与过程”先展示 Token Monitor 的项目会话用量，再展示工作台调用账本。这是两个可能重叠的观察角度，不能相加。来源通过已登记的原生会话编号认领项目；同一聊天经手多项任务只累计一次。明确的子代理会话回执也参与关联。只有来源提供真实完整工作目录时才允许精确路径匹配，不按项目名或目录简称猜测。

会话区可选今日、本月和全部历史，采用来源设备的统计窗口；与调用区的任务、Agent 和自定义日期筛选相互独立。新输入、输出、缓存读取和缓存写入分别展示，API 等价估价不代表订阅实际扣款。模型名称是来源报告，没有冒充独立身份核验。无法唯一归属、跨项目复用或多设备存在相同会话编号时不自动分摊。当前来源未提供的全部历史明细显示未知；过期窗口不计入当前范围，离线保留最后有效快照和采样时间。

旧版已结束调用只有合法整次摘要且完全没有逐事件账本时，补为只读的历史已知小计；失败但确有消耗的调用也保留。最后一条消息不能冒充整次总量。摘要不能证明全部步骤均被采集，因此完整覆盖仍为未知；筛选边界切入整次调用时不凭结束日期硬分摊。原始调用和数据库历史记录不重写。
