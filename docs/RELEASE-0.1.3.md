# v0.1.3 · 执行顺序与长需求展示

- 项目进展显示“第几步”“可执行”和“等待前序”，前序名称可直接打开。
- 团队详情增加建议派单队列，任务详情展示前序、后续与成员当前工作。
- 前序任务通过验收后自动解锁后续；派发与接单再次检查前序状态。
- 首页、需求箱和项目中的长需求默认两行，支持查看全文与完整复制，保持原有视觉设计。
- Codex 规划上下文和新执行单包含顺序信息；旧任务记录、历史执行包保持。

本次没有新增数据库迁移。升级前创建备份并从托盘退出工作台，覆盖程序文件时保留 `data/`、`config/local.json` 和 `.agent-workbench/`，详见 [使用与维护](USAGE.md#升级到-v013)。

提供 Windows x64 便携包、源码包及 SHA256 校验文件。验证范围见 [验证说明](VERIFICATION.md)。
