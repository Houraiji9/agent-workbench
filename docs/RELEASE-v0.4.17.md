# v0.4.17

- 提需求时可预选执行与审查 Agent、模型，允许部分填写；规划包直接沿用已选值，只补留空项。预览展示实际保存结果，换 Agent 不带回旧模型。
- 规划后任务页可直接修改执行和审查安排。正在执行的进程不被热切换，历史执行与审查记录保留；后续派发使用有效安排，明确清空模型也会保留。
- 客户端统一显示 DeepSeek Harness。显式 provider/model 原样传递，缺省 provider 可从当前 headless 配置唯一匹配；不再根据 GLM 或 DeepSeek 模型名前缀猜供应商。无模型时沿用客户端默认配置，未知或多供应商时给出具体修复提示。
- 当前执行会话可分页查询、批量登记项目文件分类，记录真实会话来源和用途。用户分类优先；刷新保留 Agent 分类，未知与部分扫描如实显示。分类不会移动或删除文件。
- 用量与过程展示当前交接摘要和分页来源，完整关系统一到关系图页；任务定位、历史与独有来源保持可达。
- 用户可编辑、删除、恢复自己或 Agent 记录的经验。删除从默认检索与上下文生效，修订、原作者、确认依据和替代关系保留。
- 团队详情左右区域独立滚动，切换 Agent 保留列表和页面位置；同页导航不再触发全局滚顶。
- Grok 审查提示明确最终文件指纹由工作台记录，不要求为最后核验再调用终端。取消无报告仍保留失败；有效原生会话续接的正式报告回到原审查单。
- 系统核实已记录进程不存在后自动更新恢复状态，记录系统证据，不要求用户确认机器事实；中断保留，不能据此推断审查通过。续接目标须能沿调用链追溯到实际返回的原生会话。
- 调整审查者或模型时备注可选，自动保存操作原因；清空模型明确生效，保存失败就地展示具体原因。

验证使用隔离账本。各功能逻辑、HTTP、浏览器定向结果和 TypeScript/构建结果见本轮交付报告。扩展回归中六项既有断言在未修改 HEAD 同样失败，原始失败及基线比较均保留。真实模型调用、正式独立审查、本机安装和用户试用分别记录，不以合成测试替代。
