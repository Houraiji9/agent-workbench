# Agent 客户端识别

在「设置 → Agent 客户端」点击刷新。工作台只在本机 PATH、Windows 安装登记和有限的常见位置查找，不扫描磁盘，也不把本机安装地址写入发布包。安装或移动客户端后再次刷新即可重新检查。

Windows 下刷新会重新读取用户和系统保存的 PATH，因此工作台启动后新安装的客户端也能被发现。工作台只读取这些设置，不修改全局环境变量。

新版 Cursor Agent CLI 的 Windows 启动文件包含版本选择和更新逻辑。工作台检查已知格式后，直接使用安装目录内已存在的固定版本 Node 和入口脚本核验帮助与版本；不会为了识别客户端执行更新脚本。遇到未知启动格式、缺文件或越界链接时会保留未验证状态，而非尝试执行任意脚本。

识别结果分别说明程序是否存在、版本和支持能力。识别成功不证明已经登录、有剩余额度或已成功调用模型。Cursor 的当前接入能力用于只读独立审查，调用时明确使用 CLI 的 plan 模式；未确认支持该模式的版本不会获得自动审查能力。不启用强制写入权限。

Claude 桌面应用和 Claude Code CLI 是不同入口。自动调用需要能被工作台验证的 CLI；无需为了识别问题重复安装已经存在的客户端。自动发现仍失败时，在高级修复中指定实际 CLI 路径，未知格式仍须验证，不会因手动指定而跳过检查。
