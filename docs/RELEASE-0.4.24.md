# 0.4.24：外部服务与 Harness 图片工具

团队页新增“外部服务”。用户可以从国内 API、CLI、Agent CLI 和应用 MCP 预设创建连接，集中配置凭据、程序位置、项目与 Agent 范围，再由获准会话通过工作台 MCP 调用。

- MiniMax API、mmx、mcode、Design MCP 分开；火山方舟、即梦 AK/SK API 和 Dreamina Canvas CLI 分开。预设显示协议、已适配操作和待核验部分，保存或检测配置不会冒充账号、付费资格或生成成功。
- Windows 凭据使用当前用户 DPAPI 加密，只显示凭据字段和是否配置；调用参数、报告及发布包不携带 Key。跨电脑或 Windows 账号迁移需要重新绑定凭据。
- 提供发现、调用说明、调用、状态查询和产物读取五个 MCP 工具。身份来自已认证会话，连接按项目和 Agent 授权，默认关闭生成消费；请求 ID 防重复，远端异步任务继续查询原任务。
- API 返回的图片、视频等产物保存到所属项目，附文件大小和 SHA-256。未知网络结果不会自动重发创建；CLI 正常退出与实际媒体生成完成分别记录。
- Harness 通过原生 `@deepseek-ai/dsh-mcp-client` 加载图片工具。桌面 profile 安装有备份和哈希保护回滚；工作台启动的 headless 会话使用绑定自身 Run 的凭据，不借用桌面全局身份。既有文本 provider、模型和 Key 保留。
- Cursor 的已授权只读审查自动准备本次文件指纹、BOM 和 PowerShell 5.1 静态解析命令，临时权限仅匹配该命令，确认进程退出后自动回收。原有配置、显式禁止规则、并行调用和用户同时修改的内容保留；无需用户为同一范围反复批准或手工中转。文字交付不因缺少文件被阻断，回收暂时失败会自动重试。

本版未自动购买额度、开通服务或执行收费生成。连接与调用方式见 [外部服务](EXTERNAL-SERVICES.md)。独立审查、安装和用户试用结论分别记录。
