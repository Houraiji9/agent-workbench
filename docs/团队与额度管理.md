# 团队与额度管理

## 添加常用工具

打开 **团队 → 预设库**，按名称、用途搜索，或筛选国内、国际、开发、办公工具。点“添加到团队”，确认名称和分工，再点“加入团队”。

首批有 42 个预设：Codex、Claude、Claude Code、Antigravity、Cursor、GitHub Copilot、Devin Desktop / Windsurf、Devin、Lovable、v0、Bolt、Kiro、Cline、OpenCode、Gemini CLI、JetBrains Junie、Replit Agent、ChatGPT、Gemini 应用、Grok 网页、Grok Build、Grok Bot、Perplexity、Manus、OpenClaw、Zcode、DeepSeek Harness、Kimi、Kimi Code、WorkBuddy、CodeBuddy、TRAE 国内版、TRAE 国际版、Qoder、通义灵码、Qwen Code、千问、MiniMax Agent / Code、扣子、豆包、腾讯元宝、智谱清言。

每个预设都有官方介绍链接，核验日期为 2026-10-21。Windsurf 的官方文档已转到 Devin Desktop，保留两个名称便于查找。用途与初始分工是工作台的建议，可以修改。新增的多模型工具先由执行者选择模型，也可手动补充常用型号；原有团队的已核验目录继续提供。

桌面版点 **官方介绍**，会在系统默认浏览器打开，工作台保留当前页面与筛选。成员详情中的 **官方资料** 也采用同样方式。

加入团队后，订阅在“订阅与日程”登记，额度在“额度”页添加。原有团队保持原样，预设库中已在用的工具显示“已在团队”。

## 自定义成员与模型

团队页右上角点 **新增团队**，填写名称、适合做什么，勾选可以分配的工作。图标可以使用已有软件图标或名称缩写。

点开成员后，使用 **编辑分工** 修改资料，或点 **编辑模型** 管理模型列表。模型名称用于展示；型号用于派单，留空时使用模型名称。每项可以填写建议用途、调整顺序或删除。

保存后，Codex 下一次读取工作台就会看到最新资料，按照需求选人、选模型、生成执行单。

成员详情右上角的垃圾桶可移除成员。若还有关联任务，会列出需先处理的任务；完成、取消或改派后再删除。**团队 → 已移除** 可以恢复；预设库也会显示“恢复到团队”，原资料和关联一起保留。

**已移除** 与预设库使用相同的图标卡片。找到对应成员，点卡片上的 **恢复到团队**，即可继续使用原来的分工和模型。

## 添加自己的额度

打开 **额度与订阅 → 额度 → 添加额度**，填写名称，勾选使用这份额度的成员。

- **剩余百分比**：填写 0—100。
- **积分**：填写剩余积分。
- **账户余额**：填写金额、选择币种。
- **剩余次数**：填写数量，单位可以是次、条、Token 等。

知道总量时可以填写，页面就会显示进度条。暂不清楚的数值留空；填写 0 会保存为 0。每项可以增加多个窗口，例如“5 小时”“每周”。重置时间可选填。

多个成员共用资源时，在同一项额度里勾选它们。页面和 Codex 规划保留一个额度池。

## 修改已有额度

卡片右上角的 **管理额度** 可调整名称、共用成员，也可以删除。页面下方 **已移除的额度** 可以恢复。

手动额度在管理窗口里改数值。Token Monitor 的额度继续自动同步；Claude、Antigravity 保留“编辑额度”，WorkBuddy 保留“填写积分 / 修改积分”。

DeepSeek 与 WorkBuddy 各用一张卡片，样式与其他额度一致。更新时间和编辑入口统一放在卡片底部，同排卡片顶底对齐。

所有设置保存在本机，关闭再打开会保留。两个窗口同时编辑同一条资料时，后保存的窗口提示资料已更新；重新打开即可继续。

首页额度概况会纳入刚填写的百分比，以及填写了总量的积分或次数，并按剩余比例排序。只改名称或恢复已删除额度时，保留原数值的更新时间。

## 当前接入范围

Token Monitor 和 AgentsView 需要配置自己的连接。预设工具可以加入团队，通过手动执行单工作；自动读取额度和会话使用这两个服务已经支持的数据来源。新平台的自动采集需要相应适配。

团队、模型和额度自定义管理已实现。首次使用与连接步骤见 README 和 docs/INTEGRATIONS.md。


## 每月刷新的积分

WorkBuddy 卡片点 **修改积分**，填写总剩余积分，勾选 **包含每月刷新的基础积分**，再填写 **每月基础积分** 和 **本月剩余积分**。刷新日期稍后补也可以。

示例：总剩余 800，其中月度剩余 100 / 基础 200，页面显示月度剩余 **50%**，其他积分 **700**。月度剩余已包含在总数里。

千问等其他工具：点 **添加额度**，类型选 **积分**，同样勾选月度基础积分。月度剩余不清楚时留空。到刷新日时核对平台实际记录，再更新数值。

## 结果不满意时

任务详情点 **不通过，退回修改**。无需勾选通过项，用自己的话写哪里不满意，再点 **确认不通过**。随后点 **复制返工要求**，粘贴回原执行者会话即可。

工作台会保存你的意见，并为返工生成新的执行单。重复复制会取回同一份；发出后仍由执行者报告接单。旧交付、审查和使用意见都留在任务里。再次交付后重新审查和确认。
