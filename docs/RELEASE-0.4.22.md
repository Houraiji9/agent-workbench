# 0.4.22

- 页面会话过期后自动续期；从托盘、休眠或断网恢复时重新同步，保留当前页面和编辑草稿。
- 数据源刷新合并重复请求，完成后再安排下一次；退出时取消未完成的读取。
- 区分连接成功与来源数据新鲜度，保留最近有效记录；错误显示拒绝连接、超时等具体原因。
- 减少 AgentsView 分页导入时重复读取全部会话的开销。
- 历史回执按执行编号和序号直接查询，避免后台反复解析整个事件账本占满 CPU、拖慢数据连接。
- 桌面版定期检查已配置的托管服务，分别恢复已退出的服务；保留进程身份校验、恢复频率限制和历史日志。
- 启动脚本退出后有界排空输出，不再等待后台子进程关闭继承的管道，避免服务检查与退出流程一直挂起。
- 沿用原有界面风格，统一输入区高度，改善说明文字换行和卡片间距，并核对窄窗下按钮完整可见。

外部 Token Monitor 的同步模式、账号状态与采集时间仍由原软件管理。工作台不会为了恢复连接修改第三方账号或同步设置。
