# 0.4.16

- 今天、任务详情和流程步骤展示每位审查者及已回报人数，支持两人、三人或更多审查者。
- 审查客户端退出但没有报告时，显示“待继续 · 尚未回报”；保留原调用原因和退出码，不把一次调用失败当作整个任务失败，也不遮住其他正在审查的成员。
- 共同交接入口适用于所有未回报成员，配置了调用路线的成员可单独继续。导入已有报告不依赖其他成员的运行状态；报告已回齐后优先展示负责人决定。
- 修复“提需求”中规划人与需求重要程度下拉框被拉伸、上下错位的问题。
- “交给审查者”一次复制共同交接，不再先打开详情或逐人选择。交接单不指定接收者或模型，收到的 Agent 接单后登记实际身份；多人共用入口，各自回传报告。
- 执行者或接单的审查者可按用户口述安排同伴；审查连接支持本轮同伴的调用和进度查询，用户不用逐人转单。

客户端自身拒绝终端检查仍按实际情况记录，工作台不能替客户端授予权限或把未执行的检查记为通过。
