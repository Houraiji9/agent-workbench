# v0.2.0：简版续作、清晰待办与真实关系图

本版减少重复上下文和手工回报步骤，并把源码交付与本机安装区分开。现有 Task、Run、审查和用户验收记录继续保留。

## 主要变化

- 同会话通过简版/增量上下文继续工作；新执行包使用简短 RUN.md，完整合同与返修历史按索引读取。支持一个真实原生会话关联多个任务，历史关联不能扩大权限。
- 新增 Run 限域的上下文确认、简洁回报、状态等待和收尾接口，以及 `scripts/agent.ts`。程序填写身份、工作目录、版本和序号，执行者填写实际结果。
- 首页按待回答、待试用、异常需决定、待安排分组，支持项目、负责人、搜索、动作筛选、排序和加载更多。待安排默认收起，已保存的回答转为续作事项。
- 项目可分别登记源码目录、运行目录和交付目标。显式选择的交付目标不能被规划静默降级；本机目标需要匹配当前受审清单的安装证明，才能完成收尾并交用户试用。
- 项目关系图读取真实依赖、返工、执行、审查与会话关联，支持分支汇合、历史筛选、缩放和节点详情。静态 Archify 快照另行保留。AgentsView 提供会话来源，任务依赖由工作台账本决定。
- 项目长说明默认三行、支持展开全文，保留段落与原始内容；项目资料区分源码和运行位置。开发前端代理跟随开发后端配置，便于与日常安装版共存。
- 健康接口从当前运行目录读取版本，避免仍显示旧的固定版本号。

## 使用与升级

新项目默认使用简版执行资料，也可在项目资料中选择完整模式。旧执行包不重写，新 Run 才使用项目登记的源码目录。详细接口与限制见 [简版执行与真实交付](COMPACT_WORKFLOW.md)，安装和恢复步骤见 [更新说明](UPDATES.md)。

已有项目若需要本机安装交付，请先登记运行目录，再选择本机交付目标。当前安装证明支持工作台便携格式；其他软件需要相应的交付校验适配器。

本版没有增加数据库迁移编号或改变生产依赖版本。升级仍应先备份，使用完整便携包并保留原有数据、配置和执行包。

## 验证与已知限制

类型检查、构建、相关功能与浏览器回归、完整便携更新和失败回滚已验证。独立 Zcode 审查复跑 62 项单元检查和 16 项浏览器检查通过。完整口径、早期失败与修正后复跑记录见 [验证范围](VERIFICATION.md#v020-更新验证)。

- 跨客户端自动投递尚未接通时，只提供短交接入口，复制不会被记为已发送或接单。
- 上下文统计是字符数和调用次数，不是模型计费 token，也不代表固定的节省比例。
- 状态等待最多持续 30 秒，不会唤醒已经结束的 Agent 会话。
- 大型安装清单校验可能超过 MCP 客户端默认等待时间。先查询正式记录确认是否完成；内置 `scripts/agent.ts` 使用较长请求窗口，可办理部署与收尾。不要因客户端超时就推定安装失败或跳过校验。
- 独立审查通过与本机安装完成不等于用户已经验收。用户仍需亲自试用并确认。
- 本轮未调整生产依赖，既有依赖安全说明仍以 [SECURITY.md](../SECURITY.md) 为准；未重新运行依赖漏洞审计。
