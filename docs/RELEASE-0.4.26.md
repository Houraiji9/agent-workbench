# 0.4.26：API 型 Agent 与工作群自动协作

在“团队”里配置服务地址、API Key 和模型，即可把 API 型 Agent 加入项目工作群，或选择它担任负责人。工作台后端负责模型请求、工具执行和结果回流，不需要供应商提供 CLI。

- 支持 OpenAI 兼容 Chat Completions 和 Responses 的函数工具调用。
- API 成员可在群授权目录内读取和写入文本文件，使用群派活、讨论、收件箱及已配置外部服务工具。需要命令行的工作可派给已有 CLI 成员。
- Codex、Claude、Harness 和 API 型 Agent 可作为负责人或成员协作；忙时排队，结果自动回到发起者，负责人继续原会话处理。
- 密钥与 API 私有会话使用 Windows 当前用户 DPAPI 加密，页面和公开回报不返回密钥。配置与会话按群成员和版本绑定。
- 认证、额度、协议、超时和取消状态如实显示；限制自动接话和工具循环，不自动重试结果未知的写操作。

本次正式发布也包含此前本机版本的外部 API / CLI / MCP 服务预设、Harness 生图工具接入、工作群界面，以及常规独立审查核验权限的自动准备和回收。已有的 Task、Run、Review 与用户验收记录继续分别保存。

使用入口和能力边界见 [工作群说明](WORKGROUPS.md)。供应商需支持所选协议的函数工具调用，尚未逐一验证所有兼容服务；模型名保持用户输入，不自动改用其他账号或模型。API 成员的文件工具不是任意 shell，也不是完整操作系统沙箱。

升级新增迁移 015、016、017（已应用的迁移不重复写入），保留既有项目、任务和本机配置。API 凭据与当前 Windows 用户绑定，迁移到另一台电脑后需要在当地重新填写密钥。回退应同时使用旧程序与升级前数据库备份，详见 [更新说明](UPDATES.md)。

正式 Release 提供便携包、源码包和 `SHA256SUMS.txt`。安装验证、独立审查与用户本人试用验收分别记录；发布本身不代替用户验收。
